# 挑食地图 · 青岛

### Trip à la carte — 像点菜一样规划行程

一个中俄双语的青岛离线导览地图。不给你"必去十大景点"，
而是把 64 个地点摆成一份菜单，让你按天气、按时段、按心情自己挑。

A bilingual (中文 / Русский) offline trip planner for Qingdao.

**👉 打开使用：https://kaichengkou.github.io/trip-a-la-carte/**

手机、电脑都能直接打开，不用安装任何东西。

---

## 这是什么

为一位俄罗斯访客准备的青岛导览工具。左边是 64 个精选地点的「菜单」，
按上午 / 下午 / 晚上分好类；点几下挑出想去的，地图自动画出路线并算好距离，
最后可以导出一张排版好的行程卡片图片。

整个工具是**一个 HTML 文件**，没有后端、不用登录、不收集任何数据。
存进手机后即使断网也能打开（地图瓦片需要联网加载）。

## 主要功能

| | |
|---|---|
| 🗺 **64 个地点** | 12 个分类，每处都写清「值不值得去、注意什么」，而不是复制景点简介 |
| 🌐 **中俄双语** | 一键切换。地名格式为「Русское название (中文原名)」，方便直接指给出租车司机看 |
| 🕐 **按时段规划** | 上午 → 下午 → 晚上 顺序固定，避免排出「晚上去爬山」这类行程 |
| 🌧 **天气应变** | 一键切换晴 / 阴 / 雨，雨天自动只留室内项目 |
| 📤 **导出卡片** | 生成一张带地图缩略图、站点清单、紧急电话的长图，可直接发给同行的人 |
| 📍 **实时定位** | 含中国坐标偏移（GCJ-02）校正 |
| 🏷 **地名标签** | 放大后自动显示地名，带碰撞检测，不会糊成一团 |

## 目录结构

```
├── site/index.html    ← 成品（就是这一个文件，可单独发给别人）
├── docs/              ← 文字资料
│   ├── 青岛五日导览清单_按时段.md
│   ├── 青岛景点坐标.csv       （可导入高德 / Google My Maps）
│   └── 体积构成分析.md
└── tools/             ← 构建脚本（改数据时才需要）
```

## 想改内容？

地点数据都在 `tools/data_new.py`，改完重新生成：

```bash
cd tools && python3 build_ui.py
```

会重新生成 `site/index.html`。不需要安装任何依赖包。

## 技术说明

- **地图数据**用高德（国内直连稳定），**渲染引擎**用 Leaflet 1.9.4（已内联，无外部依赖）
- 坐标存 WGS84，通过自定义 `CRS_GCJ` 投影叠加到高德底图，不做纠偏会偏移约 450 米
- 配色取自中国传统色：墨色 `#1C2B33`、宣纸 `#FBF9F4`、朱砂 `#B93A32`
- 文件 344 KB，gzip 后约 106 KB
